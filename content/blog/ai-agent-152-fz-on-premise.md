Как только в брифе появляются персональные данные клиентов и слово «безопасность», разговор уходит из маркетинга в ИБ. Это нормально: AI-агент без политики данных — риск, а не инновация.

Я не юрист: ниже — **практическая рамка для решения**, не юридическая консультация. Финальные требования — с вашим юристом / DPO.

## Три уровня контура

| Уровень | Когда обычно достаточно | Сложность |
|---------|-------------------------|-----------|
| Облачный API (провайдер LLM) | Пилот, мало ПДн, NDA, обезличивание | Низкая |
| РФ-хостинг / контур заказчика в облаке | Требование «данные в РФ», корпоративные политики | Средняя |
| On-premise / private | Банки, промышленность, жёсткий ИБ, запрет внешней передачи | Высокая |

Екатеринбург и Urals B2B часто спрашивают про «свой контур» — это третья строка, не дефолт для каждого пилота.

## Что спросить до старта

1. Какие **персональные данные** видит агент (ФИО, телефон, паспорт, переписка)?  
2. Есть ли **запрет** на передачу за рубеж / внешним API?  
3. Нужны ли **логи** и срок хранения?  
4. Кто **оператор** ПДн и есть ли согласия / поручение?  
5. Достаточно ли **обезличивания** на пилоте (маска телефона, без ФИО в промпте)?  

Часто пилот можно сделать на обезличенных данных, а полный контур — на этапе системы.

## Практика для пилота

- Минимальные поля в промпте  
- Права API CRM — только нужные стадии  
- Логи доступа и версия правил  
- Отдельный тег «pilot» в воронке  

См. также [интеграции с CRM](/blog/ai-agent-i-crm-minimalnye-integracii).

## Когда on-premise обязателен по смыслу бизнеса

- Политика ИБ явно запрещает внешние LLM  
- Отрасль с аудитами (финансы, госсектор, крупная промышленность)  
- Клиентский NDA / договор с штрафами за утечку  

Цена и срок растут: инфраструктура, доступ, сопровождение. Заложите это в смету — [стоимость 2026](/blog/skolko-stoit-vnedrenie-ai-agenta-2026).

## Чего не делать

- Кормить модель выгрузкой всей CRM «для качества»  
- Хранить промпты с ПДн в личных чатах сотрудников  
- Обещать «полное соответствие 152-ФЗ» без юриста
