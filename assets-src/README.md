# assets-src

Исходники в полном разрешении. **Не публикуются** — лежат вне `public/`,
чтобы не уезжать на сервер при каждом деплое.

На сайте используются сжатые webp-версии из `public/images/`:

| Исходник              | Публикуется как                    |
|-----------------------|------------------------------------|
| `photo/pavel-formal.jpg` | `images/pavel-formal.webp` (главная) |
| `photo/pavel-formal.jpg` | `images/pavel-cmo.webp` (директор по маркетингу) |
| `photo/pavel-casual.jpg` | не используется                   |

Оригинал `pavel-about-2026.png` (8 МБ) удалён — вместо него
`images/pavel-about-2026.webp`, 176 КБ.
